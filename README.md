# PinTime (핀타임)

캘린더 기반 일정 조율 데모.

## 실행

```bash
npm install
npm run dev
```

## 화면

| 경로 | 설명 |
|------|------|
| `/` | 캘린더 — **주간**(시간) / **월간**(종일·여행) 스위치 |
| `/share` | 일정 공유 — 방 생성, 링크 복사, 앱 일정 불러오기, JSON |
| `/join/:roomId` | 링크 참여 — 이름 등록 후 일정 적용, 타인 시간 마스킹 |

## 시연

1. 캘린더에서 주간 드래그(시간) / 월간 드래그(2–4일 여행)
2. 하단 **일정 공유** → 방 만들기 → **링크 복사해서 보내기**
3. 상대: 링크 오픈 → 이름 등록 → **앱 일정 불러오기** (또는 JSON 붙여넣기)
4. 다른 사람 바쁜 시간이 회색으로 표시됨

> 데모는 서버 없이 동작합니다. 공유 링크에 방 데이터가 포함되어 다른 기기에서도 열 수 있고, 일정이 바뀌면 **최신 공유 링크 복사**로 다시 보내면 됩니다.
