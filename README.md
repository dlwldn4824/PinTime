# PinTime (핀타임)

캘린더 기반 일정 조율 데모 · AI 일정 에이전트

## 사업 소개서 (5장)

HTML 소개서: [`public/pitch.html`](./public/pitch.html)

### 1. 문제와 해결을 한눈에

톡방마다 흩어진 When2Meet/타임픽 링크와 일정 충돌 대화를 보여주고, PinTime이 확정 일정까지 이어 주는 한 장입니다.

![1. 톡방 10개, 일정은 왜 따로?](./public/pitch-export/01-problem.png)

### 2. 기존 조율 툴의 한계

문제는 “입력”이 아니라, 일정이 방마다 끊긴다는 점입니다. 링크 생성 → 반복 입력 → 톡방 간 충돌의 흐름을 정리합니다.

![2. 일정이 방마다 끊기는 문제](./public/pitch-export/02-needs.png)

### 3. AI 일정 에이전트 구조

대화 이해 → 내 일정 연결 → 충돌 자동 제거 → 후보 추천·확정. 한 번 입력한 일정이 모든 조율방에 이어지는 파이프라인입니다.

![3. PinTime AI 파이프라인](./public/pitch-export/03-concept.png)

### 4. 프로토타입 흐름

방 생성 → 내 일정 자동 반영(마스킹) → 공통 시간 추천까지, 실제 프로토타입 화면 흐름을 보여 줍니다.

![4. 방 생성부터 공통 시간 추천까지](./public/pitch-export/04-prototype.png)

### 5. 확정과 캘린더 등록

추천 일정을 확정하면 주간 캘린더에 바로 저장됩니다. 자동 마스킹·중복 방지·캘린더 등록까지 한 번에 끝납니다.

![5. 확정 한 번이면 캘린더까지](./public/pitch-export/05-impact.png)

## 실행

```bash
npm install
npm run dev
```
